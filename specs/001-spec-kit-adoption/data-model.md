# Modèle documentaire

Aucun schéma métier changé. Une feature possède spec.md, plan.md, tasks.md et des preuves.
Son statut projet est Draft, In Progress ou Complete ; Complete exige les critères démontrés.
L'identifiant est le nom du dossier specs. Le pointeur .specify/feature.json reste local.
Les anciens dossiers .specs/changes conservent leur format et leur statut d'origine.
Le registre de réconciliation distingue code présent, preuves historiques et lacunes.
